Практическая работа №2. Паспорт проекта «Электронное расписание колледжа»

| Пункт              | Содержание                                                                                                  |
| ------------------ | ----------------------------------------------------------------------------------------------------------- |
| Название           | Электронное расписание колледжа (ЭРК)                                                                       |
| Проблема           | Изменения расписания теряются в чатах и на стендах, нет единого актуального источника                       |
| Целевая аудитория  | Студенты, преподаватели, администрация                                                                      |
| Цель               | За 3 месяца разработать веб-приложение с актуальным расписанием и редактированием для администрации          |
| Результат          | Веб-приложение; БД расписания; просмотр по группе и преподавателю; поиск; отображение изменений; роли       |

 Участники

| Роль                  | Ответственность                                      |
| --------------------- | ---------------------------------------------------- |
| Руководитель проекта  | Сроки, ресурсы, коммуникация                         |
| Аналитик              | Требования, сценарии                                 |
| Разработчик           | Серверная и клиентская часть, БД                     |
| Тестировщик           | Проверка функционала и удобства                      |
| Заказчик              | Потребности, приёмка                                 |
